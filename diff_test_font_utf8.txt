+# Mobile Typography Reference
+
+> Type scale, system fonts, Dynamic Type, accessibility, and dark mode typography.
+> **Typography failures are the #1 cause of unreadable mobile apps.**
+
+---
+
+## 1. Mobile Typography Fundamentals
+
+### Why Mobile Type is Different
+
+```
+DESKTOP:                        MOBILE:
+Γö£ΓöÇΓöÇ 20-30" viewing distance     Γö£ΓöÇΓöÇ 12-15" viewing distance
+Γö£ΓöÇΓöÇ Large viewport              Γö£ΓöÇΓöÇ Small viewport, narrow
+Γö£ΓöÇΓöÇ Hover for details           Γö£ΓöÇΓöÇ Tap/scroll for details
+Γö£ΓöÇΓöÇ Controlled lighting         Γö£ΓöÇΓöÇ Variable (outdoor, etc.)
+Γö£ΓöÇΓöÇ Fixed font size             Γö£ΓöÇΓöÇ User-controlled sizing
+ΓööΓöÇΓöÇ Long reading sessions       ΓööΓöÇΓöÇ Quick scanning
+```
+
+### Mobile Type Rules
+
+| Rule | Desktop | Mobile |
+|------|---------|--------|
+| **Minimum body size** | 14px | 16px (14pt/14sp) |
+| **Maximum line length** | 75 characters | 40-60 characters |
+| **Line height** | 1.4-1.5 | 1.4-1.6 (more generous) |
+| **Font weight** | Varies | Regular dominant, bold sparingly |
+| **Contrast** | AA (4.5:1) | AA minimum, AAA preferred |

+## 2. System Fonts
+
+### iOS: SF Pro Family
+
+```
+San Francisco (SF) Family:
+Γö£ΓöÇΓöÇ SF Pro Display: Large text (ΓëÑ 20pt)
+Γö£ΓöÇΓöÇ SF Pro Text: Body text (< 20pt)
+Γö£ΓöÇΓöÇ SF Pro Rounded: Friendly contexts
+Γö£ΓöÇΓöÇ SF Mono: Monospace
+ΓööΓöÇΓöÇ SF Compact: Apple Watch, compact UI
+
+Features:
+Γö£ΓöÇΓöÇ Optical sizing (auto-adjusts)
+Γö£ΓöÇΓöÇ Dynamic tracking (spacing)
+Γö£ΓöÇΓöÇ Tabular/proportional figures
+Γö£ΓöÇΓöÇ Excellent legibility
+```
+
+### Android: Roboto Family
+
+```
+Roboto Family:
+Γö£ΓöÇΓöÇ Roboto: Default sans-serif
+Γö£ΓöÇΓöÇ Roboto Flex: Variable font
+Γö£ΓöÇΓöÇ Roboto Serif: Serif option
+Γö£ΓöÇΓöÇ Roboto Mono: Monospace
+Γö£ΓöÇΓöÇ Roboto Condensed: Narrow spaces
+
+Features:
+Γö£ΓöÇΓöÇ Optimized for screens
+Γö£ΓöÇΓöÇ Wide language support
+Γö£ΓöÇΓöÇ Multiple weights
+Γö£ΓöÇΓöÇ Good at small sizes
+```
+
+### When to Use System Fonts
+
+```
+Γ£à USE system fonts when:
+Γö£ΓöÇΓöÇ Brand doesn't mandate custom font
+Γö£ΓöÇΓöÇ Reading efficiency is priority
+Γö£ΓöÇΓöÇ App feels native/integrated important
+Γö£ΓöÇΓöÇ Performance is critical
+Γö£ΓöÇΓöÇ Wide language support needed
+
+Γ¥î AVOID system fonts when:
+Γö£ΓöÇΓöÇ Brand identity requires custom
+Γö£ΓöÇΓöÇ Design differentiation needed
+Γö£ΓöÇΓöÇ Editorial/magazine style
+ΓööΓöÇΓöÇ (But still support accessibility)
+```
+
+### Custom Font Considerations
+
+```
+If using custom fonts:
+Γö£ΓöÇΓöÇ Include all weights needed
+Γö£ΓöÇΓöÇ Subset for file size
+Γö£ΓöÇΓöÇ Test at all Dynamic Type sizes
+Γö£ΓöÇΓöÇ Provide fallback to system
+Γö£ΓöÇΓöÇ Test rendering quality
+ΓööΓöÇΓöÇ Check language support

+## 4. Dynamic Type / Text Scaling
+
+### iOS Dynamic Type (MANDATORY)
+
+```swift
+// Γ¥î WRONG: Fixed size (doesn't scale)
+Text("Hello")
+    .font(.system(size: 17))
+
+// Γ£à CORRECT: Dynamic Type
+Text("Hello")
+    .font(.body) // Scales with user setting
+
+// Custom font with scaling
+Text("Hello")
+    .font(.custom("MyFont", size: 17, relativeTo: .body))
+```
+
+### Android Text Scaling (MANDATORY)
+
+```
+ALWAYS use sp for text:
+Γö£ΓöÇΓöÇ sp = Scale-independent pixels
+Γö£ΓöÇΓöÇ Scales with user font preference
+Γö£ΓöÇΓöÇ dp does NOT scale (don't use for text)
+
+User can scale from 85% to 200%:
+Γö£ΓöÇΓöÇ Default (100%): 14sp = 14dp
+Γö£ΓöÇΓöÇ Largest (200%): 14sp = 28dp
+
+Test at 200%!
+```
+
+### Scaling Challenges
+
+```
+Problems at large text sizes:
+Γö£ΓöÇΓöÇ Text overflows containers
+Γö£ΓöÇΓöÇ Buttons become too tall
+Γö£ΓöÇΓöÇ Icons look small relative to text
+Γö£ΓöÇΓöÇ Layouts break
+
+Solutions:
+Γö£ΓöÇΓöÇ Use flexible containers (not fixed height)
+Γö£ΓöÇΓöÇ Allow text wrapping
+Γö£ΓöÇΓöÇ Scale icons with text
+Γö£ΓöÇΓöÇ Test at extremes during development
+Γö£ΓöÇΓöÇ Use scrollable containers for long text
+```

+## 5. Typography Accessibility
+
+### Minimum Sizes
+
+| Element | Minimum | Recommended |
+|---------|---------|-------------|
+| Body text | 14px/pt/sp | 16px/pt/sp |
+| Secondary text | 12px/pt/sp | 13-14px/pt/sp |
+| Captions | 11px/pt/sp | 12px/pt/sp |
+| Buttons | 14px/pt/sp | 14-16px/pt/sp |
+| **Nothing smaller** | 11px | - |
+
+### Contrast Requirements (WCAG)
+
+```
+Normal text (< 18pt or < 14pt bold):
+Γö£ΓöÇΓöÇ AA: 4.5:1 ratio minimum
+Γö£ΓöÇΓöÇ AAA: 7:1 ratio recommended
+
+Large text (ΓëÑ 18pt or ΓëÑ 14pt bold):
+Γö£ΓöÇΓöÇ AA: 3:1 ratio minimum
+Γö£ΓöÇΓöÇ AAA: 4.5:1 ratio recommended
+
+Logos/decorative: No requirement
+```
+
+### Line Height for Accessibility
+
+```
+WCAG Success Criterion 1.4.12:
+
+Line height (line spacing): ΓëÑ 1.5├ù
+Paragraph spacing: ΓëÑ 2├ù font size
+Letter spacing: ΓëÑ 0.12├ù font size
+Word spacing: ΓëÑ 0.16├ù font size
+
+Mobile recommendation:
+Γö£ΓöÇΓöÇ Body: 1.4-1.6 line height
+Γö£ΓöÇΓöÇ Headings: 1.2-1.3 line height
+Γö£ΓöÇΓöÇ Never below 1.2
+```

+## 6. Dark Mode Typography
+
+### Color Adjustments
+
+```
+Light Mode:               Dark Mode:
+Γö£ΓöÇΓöÇ Black text (#000)     Γö£ΓöÇΓöÇ White/light gray (#E0E0E0)
+Γö£ΓöÇΓöÇ High contrast         Γö£ΓöÇΓöÇ Slightly reduced contrast
+Γö£ΓöÇΓöÇ Full saturation       Γö£ΓöÇΓöÇ Desaturated colors
+ΓööΓöÇΓöÇ Dark = emphasis       ΓööΓöÇΓöÇ Light = emphasis
+
+RULE: Don't use pure white (#FFF) on dark.
+Use off-white (#E0E0E0 to #F0F0F0) to reduce eye strain.
+```
+
+### Dark Mode Hierarchy
+
+| Level | Light Mode | Dark Mode |
+|-------|------------|-----------|
+| Primary text | #000000 | #E8E8E8 |
+| Secondary text | #666666 | #A0A0A0 |
+| Tertiary text | #999999 | #707070 |
+| Disabled text | #CCCCCC | #505050 |
+
+### Weight in Dark Mode
+
+```
+Dark mode text appears thinner due to halation
+(light bleeding into dark background)
+
+Consider:
+Γö£ΓöÇΓöÇ Using medium weight for body (instead of regular)
+Γö£ΓöÇΓöÇ Increasing letter-spacing slightly
+Γö£ΓöÇΓöÇ Testing on actual OLED displays
+ΓööΓöÇΓöÇ Using slightly bolder weight than light mode
+```
+

+## 7. Typography Anti-Patterns
+
+### Γ¥î Common Mistakes
+
+| Mistake | Problem | Fix |
+|---------|---------|-----|
+| **Fixed font sizes** | Ignores accessibility | Use dynamic sizing |
+| **Too small text** | Unreadable | Min 14pt/sp |
+| **Low contrast** | Invisible in sunlight | Min 4.5:1 |
+| **Long lines** | Hard to track | Max 60 chars |
+| **Tight line height** | Cramped, hard to read | Min 1.4├ù |
+| **Too many sizes** | Visual chaos | Max 5-7 sizes |
+| **All caps body** | Hard to read | Headlines only |
+| **Light gray on white** | Impossible in bright light | Higher contrast |
+
+### Γ¥î AI Typography Mistakes
+
+```
+AI tends to:
+Γö£ΓöÇΓöÇ Use fixed px values instead of pt/sp
+Γö£ΓöÇΓöÇ Skip Dynamic Type support
+Γö£ΓöÇΓöÇ Use too small text (12-14px body)
+Γö£ΓöÇΓöÇ Ignore line height settings
+Γö£ΓöÇΓöÇ Use low contrast "aesthetic" grays
+Γö£ΓöÇΓöÇ Apply same scale to mobile as desktop
+ΓööΓöÇΓöÇ Skip testing at large text sizes
+
+RULE: Typography must SCALE.
+Test at smallest and largest settings.
+```
+

+## 8. Font Loading & Performance
+
+### Font File Optimization
+
+```
+Font file sizes matter on mobile:
+Γö£ΓöÇΓöÇ Full font: 100-300KB per weight
+Γö£ΓöÇΓöÇ Subset (Latin): 15-40KB per weight
+Γö£ΓöÇΓöÇ Variable font: 100-200KB (all weights)
+
+Recommendations:
+Γö£ΓöÇΓöÇ Subset to needed characters
+Γö£ΓöÇΓöÇ Use WOFF2 format
+Γö£ΓöÇΓöÇ Max 2-3 font files
+Γö£ΓöÇΓöÇ Consider variable fonts
+Γö£ΓöÇΓöÇ Cache fonts appropriately
+```
+
+### Loading Strategy
+
+```
+1. SYSTEM FONT FALLBACK
+   Show system font ΓåÆ swap when custom loads
+   
+2. FONT DISPLAY SWAP
+   font-display: swap (CSS)
+   
+3. PRELOAD CRITICAL FONTS
+   Preload fonts needed above the fold
+   
+4. DON'T BLOCK RENDER
+   Don't wait for fonts to show content
+```
+
